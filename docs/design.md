# 简续移动端设计

用户导入 PDF/EPUB，正常连续阅读，在需要伴读时主动标记“我读到这里”。阅读位置、伴读边界和公开分享彼此独立。

## 已确定的实现

- React Native + TypeScript + Expo development builds。书库、设置、笔记、伴读、社区均为原生组件。
- EPUB 专用隔离内容视图按章节连续滚动，保留段落、图片、标题、链接和基本语义；每次只渲染一个章节。导入时拒绝加密、路径穿越、压缩炸弹并去除脚本、表单、外部资源和样式中的网络访问。稳定定位由文件 SHA-256、章节 href、元素标识、文本上下文与比例回退组成。此适配器可替换为 Readium。
- PDF 使用 react-native-pdf 原页显示、缩放、连续滚动和页定位。书签与页级笔记可用；不伪造文本选区、高亮或全文搜索能力。
- SQLite 保存书库、阅读位置、边界、笔记、书签和配置；原文件复制到 app document 目录，导入完成前不入库。删除书籍清理本地文件和关联记录。
- 伴读默认关闭。无 AI 内容时显示真实未配置状态。用户可保存提供方名称、HTTPS 地址和模型名称；本阶段不收集密钥、不执行网络模型请求。
- 社区独立 REST 合约及可本机运行的 SQLite 服务，实现账户、帖子、回复、举报、屏蔽、删除账户。未配置时是明确未连接状态，不放模拟用户或帖子。阅读进度不自动上传。发布只上传用户主动写入的文本及明确选定的书名。

## 验证

运行导入安全、定位与边界独立性、数据持久化、社区权限和删除回归。执行 TypeScript、lint、Metro 导出、Android 编译。可用时启动现有模拟器验证原生界面；iOS 仅保留工程配置，Windows 无法执行 Xcode 编译。未运行的检查逐项记录。

## 发布边界

本项目是可运行实现及发布准备基础。未经授权不提交商店、不签名、不创建云服务或开发者账户、不上传私人 EPUB、不调用模型。真实社区公开运营仍需要认证服务部署、审核人员、服务条款和运营配置。
